# 拒识器分析实验历程

本文只记录拒识器设计、核验与选择相关的工作。

## 已有共同基础

已有实验提供 MSP、Entropy 和 Mahalanobis 三种分数，以及原始 BERT、拼写增强 BERT和干净继续训练 BERT的逐样本预测与冻结阈值。统一分数方向为越大越像 OOS。

在 `is_acceptance_95` 下，三个种子的均值分别为：

| 方法 | OOS F1 | OOS recall | IS acceptance | AUROC |
|---|---:|---:|---:|---:|
| MSP | 0.7951 | 0.8047 | 0.9513 | 0.9449 |
| Entropy | 0.8129 | 0.8417 | 0.9491 | 0.9536 |
| Mahalanobis | 0.8453 | 0.8890 | 0.9524 | 0.9765 |

在 `max_oos_f1` 下，Mahalanobis 相对 MSP 的 OOS F1 提高 6.81 pp，区间为 [5.27, 8.30] pp；相对 Entropy 仅提高 0.30 pp，区间为 [−0.88, 1.51] pp，不能据此证明其优于 Entropy。

## 输入与结果接管核验

完成快照完整性检查、657 个拒识设置的结果复算和 183 项新增门禁检查。冻结阈值和五个工作点均可由 validation 预测复现。原始 Mahalanobis 单元测试 8 项通过，当前纯函数单元测试 18 项通过。

当前快照没有三个种子的 CLS 和 FP32 特征文件，因此不能重新拟合协方差变体或扫描完整温度曲线；预测和阈值核验本身为 PASS。

## 机制与互补性

Entropy 与 Mahalanobis 仅一方拦截 OOS 的比例为 5.3%–6.6%，MSP 与 Mahalanobis 为 8.8%–12.7%，满足预设的组合扩展条件。

生成 30 条固定规则案例，覆盖只被一种方法拦截、三种方法共同漏掉、误拒和错误接纳。解释已逐条填写；重跑分析会按 row ID 保留这些解释。

## 分布拟合

记录原 Ledoit–Wolf 收缩系数：种子 42 为 0.04060，种子 43 为 0.04272，种子 44 为 0.04182，均值 0.04171。Identity、Diagonal、OAS 和 Empirical 等变体未执行，作为资产限制披露。

## 阈值稳定性

对两种阈值策略分别进行 2,000 次 validation 重采样。Entropy 在 `is_acceptance_95` 下的 test IS 接纳率 95% 区间为 94.0%–96.3%。其他方法和策略的接纳率与 OOS recall 区间均保存在结果文件中，未利用这些结果修改阈值。

## 校准与拒识分离

温度缩放使 ECE 从约 35.6% 降至 0.85%，但 MSP AUROC 下降 2.58 pp，Entropy AUROC 下降 2.04 pp。固定 validation IS 接纳率目标为 95% 时，test OOS 误接纳分别增加 16.3 pp 和 8.0 pp。结论是概率校准与 OOS 分离属于不同目标。

历史两点结果与 FP32 分数的一致性检查为 PASS；完整温度曲线未执行。

## 成本驱动选择与组合候选

使用 λ={1,2,5,10}、π={0.05,0.1818,0.30}，在 validation 上选择成本最低的候选，再报告 test 成本和 bootstrap 选中频率。

只计算 FR 与 FA 时，两个模型的 24 个设置均选择 Mahalanobis，成本主要改变工作点，最大 test regret 约 0.70 pp。计入错误接纳后，在 OOS 较少且 λ 较大的部分设置中改选 MSP。

新增 `combo_max` 和 `combo_mean`，ECDF 仅由 validation 拟合。组合分数未显示优于单独 Mahalanobis 的证据，因此保留为阴性结果，不作为改进方案。
