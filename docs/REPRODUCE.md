# Auditing and rerunning

## Fixed CSV snapshot, no GPU

From the repository root:

```text
python tools/verify_snapshot.py
python tools/verify_results.py
```

These commands write nothing into frozen experiments. Result auditing checks
the shared texts/labels, threshold decision rule, OOS F1/precision/recall,
AUROC/AP, IS acceptance/error rates, 150/151-class F1 and per-seed aggregates.
Initial BERT and TF-IDF classification results are also recomputed from CSV.
They do not establish that GPU operations ran as logged, refit calibration,
reselect thresholds or resample uncertainty intervals.

## Demo, after supplying seed-42 assets

Use the follow-up environment and retain the repository layout:

```text
python demo/demo_inference.py
```

This runs fresh FP32 inference for the presentation's two postselected examples
and checks labels/rejection against stored decisions. It needs the seed-42
model/detector files described in `ASSET_ACCESS.md`. It writes only
`demo/demo_inference_results.json`. It does not train or tune thresholds.

## New experiments

Create a separate clean copy containing the same sibling experiment names,
Python sources and public `data/`; do not copy old `outputs/`, freeze/completion
JSONs or manifests into a new experimental run. The initial typo-data directory
is generated by `src/typo_data.py` as below. Supply the approved local BERT
base-uncased pretrained weights under
`CLINC150_Team_20261019/.models/bert-base-uncased/` using the asset archive.
Use the original environment for these commands, from the team project directory:

```text
python src/eda.py --data data/raw/data_full.json --output outputs/eda
python src/baseline.py --data data/raw/data_full.json --output outputs/baseline
python src/train_bert.py --data data/raw/data_full.json --model-name .models/bert-base-uncased --output outputs/bert/seed42 --seed 42 --epochs 3 --learning-rate 2e-5 --train-batch-size 16 --eval-batch-size 64 --max-length 64
python src/train_bert.py --data data/raw/data_full.json --model-name .models/bert-base-uncased --output outputs/bert/seed43 --seed 43 --epochs 3 --learning-rate 2e-5 --train-batch-size 16 --eval-batch-size 64 --max-length 64
python src/train_bert.py --data data/raw/data_full.json --model-name .models/bert-base-uncased --output outputs/bert/seed44 --seed 44 --epochs 3 --learning-rate 2e-5 --train-batch-size 16 --eval-batch-size 64 --max-length 64
python src/typo_data.py --data data/raw/data_full.json --output outputs/robustness/typo_data
```

Original `run_multiseed_typo.ps1` records the complete training/OOS/robustness
sequence; it expects the original interpreter at the team project's `.venv`.
Its `Invoke-Experiment` calls can equivalently be run with the activated original
Python. Run `src/data_audit.py` after initial outputs/tokenizer are available to
produce the duplicate audit used by later sensitivity checks.

Then switch to the follow-up environment and run from the new workspace root:

```text
python BERT_Rejection_Study_20261019/run_rejection_study.py --stage development
python BERT_Rejection_Study_20261019/run_rejection_study.py --stage test
python BERT_Rejection_Study_20261019/run_typo_rejection.py
python BERT_Typo_Augmentation_20261019/run_augmentation.py --stage prepare
python BERT_Typo_Augmentation_20261019/run_augmentation.py --stage development
python BERT_Typo_Augmentation_20261019/run_augmentation.py --stage test
```

The subsequent experiment `RUN_README.txt` files specify their stage order,
reporting, sensitivity and verification commands. Follow-ups reuse one another's
files; keep all sibling directory names. Complete stages freeze before test
inference/rethresholding. Never delete original freeze files to force a rerun.
Fresh-run hashes and runtime records must describe the new run; they will not
match the historical source identity. This packaging step did not rerun training.
